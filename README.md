# Данные проекта: статистика прослушиваний Spotify

Дата сбора открытых данных: 08.11.2026.

| Файл | Что это | Настоящие или нет |
|---|---|---|
| plays.csv | Моя история прослушиваний, выгрузка Spotify (61 524 строки, 17.09.2024 – 03.11.2026). Без IP и страны. | Настоящие |
| spotify_quarterly.csv | Пользователи и подписчики Spotify по кварталам | Настоящие (по пересказам отчётов в СМИ, ссылки в колонке source) |
| spotify_premium_regions.csv | Доли регионов в платной базе Spotify, Q2 2026 | Настоящие |
| competitor_prices.csv | Цены и аудитория конкурента stats.fm, ARPU Spotify | Настоящие (App Store и СМИ) |
| users_synthetic.csv | Опрос 1 500 человек: возраст, часы музыки, интерес к статистике, готовность платить | СИНТЕТИЧЕСКИЕ (generate_users.py, seed 42) |

## Допущения для синтетического опроса
- Доли возрастных групп 16-24 / 25-34 / 35-44 / 45+: 38 / 34 / 16 / 12 %.
- Среднее время музыки около 1,8 ч в день, у молодых больше.
- Доля пользователей сервисов статистики: 12 / 10 / 5 / 2 % по группам.
- Интерес к статистике растёт с часами прослушивания.
- Готовность платить зависит от интереса. Цены 1, 2, 3 или 5 долларов в месяц.
Все эти числа придуманы автором как допущения и не являются фактами. Для усиления работы их можно заменить реальным опросом.
